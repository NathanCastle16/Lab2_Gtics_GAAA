# LAB1GTICS20262

Solución del Laboratorio 1 de Gestión de Servicios de TICS.

## Ejecución

1. Abrir el proyecto en IntelliJ.
2. Usar Java 17.
3. Esperar que Maven descargue las dependencias.
4. Ejecutar `Lab1GticsApplication`.
5. Abrir `http://localhost:8080`.

## Git solicitado por el laboratorio

El repositorio debe tener las ramas:

- `main`
- `develop`

El desarrollo debe realizarse en `develop` y al finalizar se debe crear un Pull Request hacia `main`.
